# Coupling Rails example

A minimal Rails application that renders and serves the checked-in files in `coupled_assets/` through Coupling. It has no Node, package-manager, or asset-compiler dependency.

Run the repository-level smoke check with `mise run rails-example`.

Start the app with `mise run rails-example-server`, then open <http://127.0.0.1:3000>. Set `PORT` to use another port.
